# Changelog

## 6.1.1

Initial public open source release of the existing personal userscript for X (Twitter).

- Full-width feed with a compact navigation rail and hidden right sidebar.
- Optional media reveal and repaired carousel spacing.
- Compact List headers with optional details and cover.
- Long-post expansion and locally saved reading settings.
- On-demand combined thread reader with bounded loading, search, copy, and print.
- Conditional **Read thread** and **Read post** labels based on confirmed reply connections, including updates when connected posts load later.
- Maintainable sources, a reproducible build, portable regression tests, and a PRD.

Runtime behavior matches the previously verified 6.1.1 userscript. Public distribution adds license and repository metadata.
